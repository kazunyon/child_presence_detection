# システム開発アウトプット一覧

## 使い方

この一覧は、依頼対象の成果物を選ぶために使う。全成果物を機械的に作成しない。システムの規模、対象範囲、契約、リスクに合わせて選び、不要なものは `対象外` と明記する。

判定はChatGPTが確認を支援できる範囲を表す。

- `◎`: かなりの範囲を確認できる
- `○`: 確認できるが、人による確認も必要
- `△`: 補助のみ。実環境または専門家の確認が中心
- `×`: ChatGPTだけでは判断できない
